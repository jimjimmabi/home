Dotoriverse Development Path
Weekend 1

The Shell

  • Built the core HTML/CSS shell with a 5-tab layout
  • Created the welcome screen with the project's dedication
  • Established the DOTORI-ID creation system
  • Set up anonymous Supabase authentication
Weekends 2 & 3

The Room & Content

  • Developed the Mini-Room with a grid-based editor
  • Added furniture, wallpaper, and floor customization
  • Implemented the Guestbook with public and secret messages
  • Created the Photo Album with upload and compression
  • Integrated a fully functional BGM player
Weekends 4-6

Community & Polish

  • Built the Acorn Square private group system
  • Implemented the "Time Capsule" (2008 ↔ 2026 toggle)
  • Added the quiet, atmospheric "Quiet Room" feature
  • Polished the UI with custom themes and pixel mode
Weekend 7

Going Online

  • Flipped the switch from localStorage to Supabase
  • Deployed the first fully online version
  • All user data now persists and syncs in real-time
Weekend 8

Taste Finder & Friends

  • Developed the "Taste Finder" matching algorithm
  • Built the real-time chat system (쪽지)
  • Created the "Ilchon" mutual friend system
Weekend 9

The Soul of the Forest

  • Integrated browser notifications and in-app toasts
  • Added profile image uploads and a birthday system
  • Polished UX with features like "Days Together"
Weekend 10

MyDesk — The Personal Workspace

  • Built a document editor with a word-processor toolbar
  • Added tasks, calendar, and Pomodoro focus timer
  • Connected MyDesk to the same Dotorisup account
  • Enabled real-time cloud sync to Supabase
Weekend 11

The Dotoriverse Homepage

  • Created a portal-style homepage for all tools
  • Inspired by 2008 Asian search-engine portals (Naver, Daum)
  • One hub for every project, social, and update
